## 🚀 Live Review & Deployment (GitHub Pages)

This project is built using semantic **HTML5**, **CSS3**, and modern vanilla **JavaScript** with zero build-step dependencies, making it directly deployable on **GitHub Pages** or runnable locally with Node.js.

### 💻 Running Locally:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### To Deploy to GitHub Pages:
1. Initialize/push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: complete Fareedsons Enterprises proposal with Neo Gen Technologies branding"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. In your GitHub repository:
   - Navigate to **[Settings > Pages](https://github.com/faxingberling1/fareedsons-enterprises/settings/pages)**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select Branch: `main` and folder `/ (root)`.
   - Click **Save**.
3. Your proposal will be live at:
   👉 **[https://faxingberling1.github.io/fareedsons-enterprises/](https://faxingberling1.github.io/fareedsons-enterprises/)**
